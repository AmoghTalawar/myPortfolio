Selected work in AI, networking and systems

5G · Edge · Research

Private 5G Testbed with AI Task Offloading

A hardware-based private 5G standalone network with an edge-cloud continuum, used to evaluate intelligent task offloading.

  • USRP B210 + srsRAN gNB (Band n78, 20 MHz TDD) with an Open5GS core
  • MicroK8s edge running 9 CIFAR-10 inference pods, with an OpenStack cloud backup
  • MILP gateway and DQN scheduler, extended with GNN-based node scoring
  • Testbed results: about 56% lower latency vs. a cloud-only baseline

Deep Learning · OCR

Kannada Handwritten Word Recognition

CNN–BiLSTM model with multi-head self-attention for recognising Kannada handwritten words.

  • 0.95% CER and 6.09% WER on IIIT-Indic-HW-Words (13,371 test samples)
  • 30.5M parameters, CTC loss with adaptive label smoothing, SWA
  • Published and presented at ICRACS 2026

Networking · Simulation

Dual-Region Hospital Network in ns-3

A simulation of two hospital regions (Bengaluru and Mysuru) with department-level LANs and inter-region routing.

  • Core plus 7 distribution routers per region: ICU, Radiology, Staff, ERP, Servers, WiFi, Mgmt
  • RIPv2 inside each region, static peering between cores, dual-homed ISP edge
  • Hamming(31,26) UDP transfer, EHR/PACS TCP flows, video, analysed with FlowMonitor and NetAnim
ns-3.43C++RIPFlowMonitor
